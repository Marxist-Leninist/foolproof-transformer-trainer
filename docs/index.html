Get started

Download once. Train on your machine.

Windows

  1. Download the ZIP and extract it.
  2. Open the extracted folder and double-click START-WINDOWS.bat.
  3. Review the setup, wait for dependencies, and open the local app in your browser.

If a security warning appears, verify the source before deciding whether to run downloaded software.

macOS or Linux

  1. Download and extract the ZIP.
  2. Open a terminal in the extracted folder.
  3. Run bash start.sh and wait for setup.

Read the launcher before running it. The repository includes full installation and troubleshooting instructions.

First start needs internet and downloads Python, PyTorch and other dependencies. Allow several GB of disk space; GPU installs can be larger. Local electricity, internet and storage costs still apply. Compatibility varies: check the current platform tests rather than assuming all hardware is supported.

Good questions, before you start.

Does this train a frontier AI?

No. It trains small models from scratch for experimentation. Useful general-purpose models require substantial data and compute. A short laptop run is not equivalent to a large pretrained assistant, and may generate nonsense or inaccurate content.

What is a Hugging Face dataset?

A dataset is a collection of examples for a model to learn from. Hugging Face hosts many collections, with different formats, licenses and access rules. Choose text you are permitted to use and inspect its preview before downloading.

Where does my data go?

Training takes place on the computer running the app. Public dataset search and downloads contact Hugging Face. Exporting or publishing a model is a separate action: review what you share and never include private training data or credentials accidentally.

Can I use this website as the trainer?

No. GitHub Pages hosts static files and does not provide the Python training backend. Download and run the local app, which opens its own browser interface. Nothing is training just because you are viewing this page.

Where are the code and installation instructions?

Open the GitHub repository for the source, MIT license, setup guide and platform test results.
